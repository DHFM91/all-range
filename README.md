# All-Range

A free-flight 3D arcade dogfighter that runs in your browser. Fly anywhere inside a large circular combat zone, clear the enemy carrier's fighters out of the sky, and see how many hits you can rack up before your ships run out.

**Play:** https://dhfm91.github.io/all-range/

## Controls

| Key | Action |
| --- | --- |
| WASD / Arrows | Steer (T toggles inverted pitch) |
| Space / J | Fire. Hold to charge, lock on, release |
| B / K | Bomb (press again to detonate) |
| Shift | Boost |
| Z | Brake |
| Q / E | Bank for tight turns |
| C | Deflector shield (bounces enemy fire back) |
| R, or pull up + boost | Loop (get behind a pursuer) |
| F, or pull up + brake | U-turn |
| V | Camera (chase / cockpit) |
| M | Mute |
| P / Esc | Pause |

Gamepads work too: left stick steers, A fires, X bombs, RT/LT boost and brake, LB/RB bank, left stick click raises the shield, Y loops, B U-turns.

## On a phone or tablet

Touch controls appear automatically. Drag anywhere on the left side to steer (push all the way sideways for a tight turn). The right thumb gets FIRE (hold to charge a lock-on shot), SHIELD, BOOST, BRAKE, BOMB, LOOP and U-TURN. Landscape works best.

## Running it locally

Download `index.html` and open it in a browser. It needs an internet connection the first time, because the 3D engine ([Three.js](https://threejs.org)) loads from a CDN.
